# Global Cursor rules

`~/.cursor/rules` links here (`script/setup-cursor.sh`). These rules apply in every repo, so they stay generic and few:

| Rule | Applies |
| --- | --- |
| `github.mdc` | always: git and GitHub habits |
| `cursor-rules.mdc` | when editing `.cursor/rules/**` |

Project conventions belong in each repo's own `AGENTS.md` and `.cursor/rules/`, not here.
