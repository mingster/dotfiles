# Global Cursor rules

`~/.cursor/rules` links here (`script/setup-cursor.sh`). A real `~/.cursor/rules` folder is first moved to `~/.cursor/rules.bak-<timestamp>`, so copy any rule you want to keep back from there. These rules apply in every repo, so they stay generic and few:

| Rule | Applies |
| --- | --- |
| `github.mdc` | always: git and GitHub habits |
| `cursor-rules.mdc` | when editing `.cursor/rules/**` |

Project conventions belong in each repo's own `AGENTS.md` and `.cursor/rules/`, not here.
