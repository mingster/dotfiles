# Obsidian vault (agent memory)

Vault layout and sync setup. Not loaded every session. Read this before changing
`script/setup-obsidian.sh`, the vault structure, or the MEGA sync configuration.

## Obsidian vault structure

| Note | Purpose |
|------|---------|
| `Projects Index.md` | All active projects with links to their pages |
| `Tech Notes Index.md` | Cross-project tech patterns (stack, Next.js, Prisma, server actions) |
| `Tech Notes/` | Extended versions of each notes/ topic |
| `Riben Life.md` / `Mingster Com.md` / `Pstv.md` | Project overview pages |
| `Riben Life Docs/` | Full architecture docs for riben.life |

The `obsidian` MCP server config lives in `~/.claude/settings.local.json` (generated by
`setup-obsidian.sh`, not committed). Fetch notes via `read_file_content("Tech Notes Index.md")` etc.

## Vault sync (MEGAcmd)

`setup-obsidian.sh` (called by `install.sh`) installs MEGAcmd on both macOS and Arch, prompts
for MEGA login if not already authenticated, and configures background sync of
`~/Documents/Obsidian` to `MEGA:/Obsidian`. The whole flow runs as part of `sh install.sh`.

To re-run just the Obsidian setup (e.g. on a new machine after cloning dotfiles):

```bash
bash script/setup-obsidian.sh
```
