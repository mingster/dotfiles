# qa-sdet execution reference

## Execution
- Before installs/builds run `df -h /`; stop on low disk. Never move dependencies/worktrees to temp.
- **Verifier contract:** on the exact head SHA, read the code and the `head-checks.sh` Checks receipt, which must be PASS (a red one stops the line). Do not run tests, tsc or lint, nor `script/checks-local.sh` when GitHub Checks are green at the head. Prove the load-bearing behaviour live (browser at a phone viewport for UI, real API request, or real script or job run), and audit the full diff against the spec. Walk the Acceptance list per `team.md`, Verdict; a proof you cannot reproduce counts as unproved. Docs only PRs use `head-checks.sh`'s doc link check.
- Return `Verdict: PASS|PASS+NOTES|FAIL head=<full sha> verifier=<dispatch id> author=<dispatch id>` as the first line, then what ran and what was observed, posted by you as a PR comment. Verifier, author and lead use distinct dispatch IDs. Cover every Unchecked path from the Checks receipt in the live lane and mention unchecked coverage in the Verdict. Partial or blocked verification is FAIL with the blocker, never PASS; first rerun a failed environment step (install, server start) once.
- Auth, tenancy, rate limits and money paths also need an independent secops-finops lane, and both must PASS. Verifier model and provider: `.claude/model-routing.md`; family rule: `team.md`, Verdict. When no other family has quota, a different Claude model is tagged `same-family-different-model`. Never the same agent and model. qa-sdet may use Cursor grok for a Claude-built PR. No live access blocks the lane.
- Each new head needs fresh checks, except a clean merge of trunk, which carries the Checks PASS and the Verdict (`ship.sh`, `verdict_carry`); an authored or conflict edit needs a new verdict. Gate loosening needs the coordinator's current-head countersign.
- **Local servers:** start your own server on your own port. Never stop one by name (`pkill`, `killall`; the guard denies it). Stop it with `kill $(lsof -ti tcp:<port> -sTCP:LISTEN)`, or `kill` on a pid saved from `$!` in a pidfile.
- **Paths:** quote bracketed paths; no escaped paths, `..` or paths outside the worktree; scratch goes in `<worktree>/.scratch/`; temp files never loose in `/tmp`.
