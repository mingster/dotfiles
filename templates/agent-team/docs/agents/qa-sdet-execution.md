# qa-sdet execution reference

## Execution
- Before installs/builds run `df -h /`; stop on low disk. Never move dependencies/worktrees to temp.
- **Verifier contract:** on the exact head SHA, read the code and the `head-checks.sh` Checks receipt, which must be PASS (a red one stops the line). Do not run tests, tsc or lint (user rule 2026-10-27). Prove the load-bearing behaviour live (browser at a phone viewport for UI, real API request, or real script or job run), and audit the full diff against the spec. Walk the PR body's Acceptance list item by item: an item with no proof, or a proof you cannot reproduce, is a FAIL that names the item. Judge the brief, not taste; anything beyond it becomes a follow up issue, not a FAIL (owner 2026-11-13, #986). Docs only PRs use `head-checks.sh`'s doc link check.
- Return `Verdict: PASS|PASS+NOTES|FAIL head=<full sha> verifier=<dispatch id> author=<dispatch id>` as the first line, then what ran and what was observed, posted by you as a PR comment. Verifier, author and lead use distinct dispatch IDs. Cover every Unchecked path from the Checks receipt in the live lane and mention unchecked coverage in the Verdict. Partial or blocked verification is FAIL with the blocker, never PASS; first rerun a failed environment step (install, server start) once.
- Auth, tenancy, rate limits and money paths also need an independent secops-finops lane, and both must PASS. Verifier model and provider: `.claude/model-routing.md`; the verifier is a different model family from the builder (sonnet and opus are one family). No live access blocks the lane.
- Each new head needs fresh checks, except a clean merge of trunk, which carries the Checks PASS and the Verdict (`ship.sh`, `verdict_carry`); an authored or conflict edit needs a new verdict. Gate loosening needs the coordinator's current-head countersign.
- **Local servers:** start your own server on your own port. Never stop one by name (`pkill`, `killall`; the guard denies it). Stop it with `kill $(lsof -ti tcp:<port> -sTCP:LISTEN)`, or `kill` on a pid saved from `$!` in a pidfile.
- **Paths:** quote bracketed paths; no escaped paths, `..` or paths outside the worktree (they stall approval); scratch goes in `<worktree>/.scratch/`; temp files never loose in `/tmp`.
