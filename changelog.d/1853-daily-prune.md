The daily wrap-up round now prunes: it keeps only `main`, `production`, `staging` and active work (an open PR head, a live worker's worktree, a worktree with uncommitted changes, the main checkout) and deletes every other worktree and local branch, and on the coordinator host every other origin branch. Each delete is first written to `~/agent-state/branch-prune/<date>.tsv` for restore. Any lookup it cannot read stops the deletes in that repo.
