- guard-bash: a variable the same command sets to a literal (`X=/path`, or `for X in a b`) is judged by its value, so `ssh $h`, `scp ... "$S/"` and `$P/.claude/...` in such a command are no longer denied. A value from `$(...)`, `read`, the environment or a second assignment still is. `ssh` after `do`, `then` and the other leading keywords is now checked, and scp and rsync judge only operands with a `:` as hosts.
