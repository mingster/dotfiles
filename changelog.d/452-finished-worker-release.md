- `worker-finish.sh` and `worker-pane-close.sh` treat native `worker-release --json` as the lifecycle authority: strict `ok`, CLI exit, requested dispatch id, and `state`/`processAction` before worktree removal or terminal close. Retained, pending, malformed, and id-mismatch receipts fail closed; dirty or unmerged worktrees are kept after release. Pane close no longer uses the shared retry loop; every close path re-validates with `worker-release` before a single verified `terminal close`.
