secrets-gate-setup: on macOS, a receiver or source run on a host whose folder already exists but is not root 700 stopped at the "hand the top of the folder to root" step with "chown: --: No such file or directory". BSD chown reads the owner as the first operand, so the `--` after it was taken as a file name. The two chown calls now put `--` before the owner, and the test suite checks the BSD argument order (Refs #1888).
