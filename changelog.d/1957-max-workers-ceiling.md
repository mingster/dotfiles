- fleet-watch: `work_order.max_workers` sets a fleet ceiling. At N live workers the issue scan, rework and verifiers start nothing, except one verifier over it for a pull request that passed Review, and the fill gap line says `at max_workers N`. `worker-startup.sh` refuses a hand start over the ceiling unless given `--force-over-cap <reason>`, which it logs. Without the key nothing changes. fleet-watch also logs one `metrics` line per hour (merged PRs, first pass PASS rates, wasted starts, median open to merge hours, mean live workers), and `wrap-up.sh` prints the last 12 (#1957).
