The template guard now carries the rules a hand kept project guard had on its own, so such a project can adopt the template copy with no loss. Two new guard-config.json keys: `force_push_branches` (branch globs a force push needs `force-push <branch>` for, default `["main"]`, `["*"]` guards every branch) and `secrets_dir_exceptions` (the sentences the secrets dir deny shows for the scripts that may read it).
A configured approval folder is now closed to Edit and Write as a whole, not only its `approval.json`. An approval whose `expires_at` is NaN no longer counts as live. A quoted heredoc fed to `git commit -F -` is read as a commit message, not as commands. The template hook test brief now meets the current brief-lint rules, so all template hook tests pass again.
