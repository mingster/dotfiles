guard-bash: a command that may commit is now refused when it stages or moves a path without `git add`: `git rm`, `git mv`, `git apply` and `git update-index` (#2030). The plain commit gate (#2023) cannot tell which path those change, so they fail closed. `git commit -o`, `-i`, `--only` and `--include` naming a protected path keep the owner gate, and the guard tests now record each form (#2030).
