* The guard now denies a command that names a blocked script unless every shell line is plain: quotes open and close on the line, no backslash, `$`, backtick or process substitution, and at most one closing `<<'TAG'` heredoc. Each plain line is checked on its own, and a heredoc body may name the script only when it feeds a text sink such as `cat > file` or `git commit -F -`. Glued perl code flags such as `perl -esystem...` are now scanned as code. This closes the quote, comment and heredoc tag bypasses in #1381 and #1383.
