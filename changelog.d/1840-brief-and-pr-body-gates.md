- Brief lint and the PR body gate catch more missed steps (#1840). `script/brief-lint.sh` refuses a brief that runs `install-fleet-automations.sh`, a `setup-*.sh` or `install.sh` unless the first run uses `--dry-run` and the brief has a `Side effects:` line; a script with no `--dry-run` (install.sh and every setup script today) cannot be run from a brief. A run under Out of scope, Allowed files or a Problem or Background section does not count. A build or rework brief whose Allowed files is under `web/src/app` or a `components` folder needs a `390x844` phone step, and a brief with an explicit `Type: build` line needs a `Tests:` line naming test files (the dotfiles brief template now carries one). `script/pr-body-gate.py` has two opt-in rules: with `--diff <file>`, a change to an existing function or field needs a `Readers:` section naming each changed name, every caller with a test or a reason; with `--asked no`, the body needs a `Decisions:` section (`Decisions: none` is fine). Without those options the gate behaves as before.
