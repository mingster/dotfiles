guard-bash: an interpreter that reads its code from a quoted stdin heredoc is judged by that body only when the whole command is exactly `<interpreter> [-] <<'TAG'`, the body and one closing `TAG` line (#1360). Any other shape (a pipe, another line, an fd, a flag, an argument) is judged as a whole, as before. A command the shell parser cannot tell apart is also checked line by line, and `ShellLines` marks `case`, a trailing `\` continuation, `#` after `)`, `\` in a quoted heredoc delimiter, a delimiter ending in `\` and a `$'` delimiter as unsure, so they scan the whole command (#1359 follow-up).
