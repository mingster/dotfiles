guard-bash: an interpreter that reads its code from a quoted stdin heredoc is judged by that body only, not by the rest of the command (#1360). A command the shell parser cannot tell apart is also checked line by line, and `ShellLines` marks `case`, a trailing `\` continuation, `#` after `)` and `\` in a quoted heredoc delimiter as unsure, so they scan the whole command (#1359 follow-up).
