guard-bash: an interpreter that reads its code from a quoted stdin heredoc is judged by that body only, not by the rest of the command (#1360). When the helper cannot prove the body (an fd or glued flag heredoc, an unquoted or nested heredoc, an escaped or quoted interpreter name) it returns the whole command, and a glued `-e` code flag is judged by its code. A command the shell parser cannot tell apart is also checked line by line, and `ShellLines` marks `case`, a trailing `\` continuation, `#` after `)`, `\` in a quoted heredoc delimiter, a delimiter ending in `\` and a `$'` delimiter as unsure, so they scan the whole command (#1359 follow-up).
