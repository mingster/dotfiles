- `secrets-gate.sh run <helper> [args...]`: runs a fixed helper from the root owned `/opt/secrets-gate/helpers` folder in an empty environment with `SECRETS_GATE_FOLDER` set, refusing (exit 2) a link, a writable or non root helper and any name that is not plain. `secrets-gate-setup.sh --helpers <dir>` installs the helpers root 755 on source and receiver hosts and writes a passwordless `run *` sudoers entry on both (plus `sync` on the source) (#1888).
