- `guard-bash.py`: closes four text check bypasses left after #1874 (#1887). An expansion glued to a quoted or literal part of the private dir name (`"$u"fileServer`, `${S}rets`) reads as a glob, bracket globs such as `[!x]`, `[^x]` and `[[:alpha:]]` match any character, both checks also read the command with `$'..'` left as written and with `$name` ended after quotes drop (so a `$'` in a comment or `eval "\$"S` no longer hides a name), and `~-` or `cd -` is judged from every directory the command stands in. Deny only: nothing denied before is allowed now.
