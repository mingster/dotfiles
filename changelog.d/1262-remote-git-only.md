worker-startup: the remote git-only step of a `Setup: none` start read the terminal result from `terminal wait --for exit`, which times out on a remote host (the terminal is an interactive shell) and then always reports exit code 0, so every such start failed with "git-only setup failed". The command now prints its own `GIT_ONLY_RC=<n>` line and the start reads it from the terminal (#1262).
