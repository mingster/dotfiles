Fleet automation prechecks and worker-startup share one PATH helper that adds the asdf shims and `/usr/sbin` when those directories exist, so a scheduled pass can find the pinned node, `lsof` for an Antigravity quota reading, and `sysctl` for placement load. The Antigravity reader also calls `/usr/sbin/lsof` when `lsof` is off PATH. Re-run `script/install-fleet-automations.sh --install` so registered commands pick up the new PATH. A helper under `script/lib` selects the tests that reference it. (#884)
