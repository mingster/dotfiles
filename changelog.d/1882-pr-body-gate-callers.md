pr-body-gate now runs its Readers: and Decisions: rules in the fleet. check-pr-body.sh, pr-review.sh, ship.sh and fleet-watch (at worker_done) pass the PR diff, so a body that changes an existing function or field without a Readers: section is refused. fleet-watch also passes the dispatch ask record, so a worker that sent no ask needs a Decisions: section (Decisions: none is fine). check-pr-body.sh takes --diff and --asked, and with no --diff uses the checkout branch diff against origin/main.
