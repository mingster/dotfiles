* The Bash guard now denies a blocked script whose name is built from variables, brace lists, hex or octal escapes, globs, substitutions or xargs, and a blocked script run behind a shell keyword such as `then`, `do` or `!`. A quote in a comment or in an ANSI-C string no longer hides the next command from every other rule. A command that only mentions a blocked script (multi line `gh --body` text, `$name`) is no longer denied. Each blocked script can have its own deny sentence in `blocked_script_reasons`; the default one no longer says "deploy pipeline". Closes #1385.
