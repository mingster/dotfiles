guard-bash no longer refuses a gated name that only appears as text. A quoted heredoc fed to `cat > f`, `git commit -F -` or `gh ... --body-file -` is data after plain steps joined by `;` as well as `&&`, an `X=value` step among them. `shasum` and `sha256sum` read the approval file like the other viewers. Inline python code starts a process only when a name in the code (not a string) matches, unless the code imports something or uses a dunder name or a lookup builtin; code that does not parse keeps the old substring rule. The `-m` and `--message` values of `git commit` and the `--title` and `--body` values of `gh` no longer count as a secrets dir read. Perl, ruby and node code keep the old rule.
