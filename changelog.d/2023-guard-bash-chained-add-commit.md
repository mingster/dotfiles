guard-bash: a command that may commit now gets the owner gate only when it is plain (literal `git add` and `git commit` steps, no variables or substitutions in the program or folder, no `eval`, `<shell> -c`, wrappers, subshells, functions, globs or line continuations). Any other command that may commit is refused with a message that says how to split it, so a form the guard cannot read fails closed. The pass runs after the other checks, even when they raise, and replaces the commit branch of the role file gate (#2023).
