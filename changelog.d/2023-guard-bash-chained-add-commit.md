guard-bash: the commit gate now runs once over the whole command and counts every `git add` (and `git stage`) before each commit, including adds and commits inside `<shell> -c`, `eval` and `$(...)`. A path that is not literal, pathspec magic, `-p`, `xargs git add` or an unknown folder counts as `git add -A`. A command that mixes a git add or commit with a program named by a variable, a built git subcommand, a commit in an unknown folder, or text the guard cannot read is refused, with or without an `Owner-approved:` trailer (#2023).
