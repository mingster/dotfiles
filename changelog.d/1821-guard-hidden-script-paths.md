guard-bash judges a variable path by its values when the command fits the closed shape of #1795. A word such as `$P/.claude/skills/*/SKILL.md` or `../$w` is no longer a hidden path deny when every value it can take, matched to its statement and position, reaches no protected path: no exact or case folded hit, and for a value that still holds a glob, no `..` part, no protected path below its fixed prefix and no hit from the glob. Any other shape, or a command the two word readers split differently, is judged as before.
