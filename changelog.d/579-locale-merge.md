Lead merge no longer refuses a locale JSON file that main and the PR changed on different keys. When the three way merge is clean and every merged key holds the value of the side that changed it, the project's one line locale check in `.agents/locale-merge-check.conf` (read from main) runs on the merged tree, and a pass accepts the merge. Without that file, or on a failure or timeout, the old refusal stands, and the same key changed on both sides still refuses.
