The template guard has a new `guard-config.json` key, `exact_only_scripts` (a list of repo relative script paths). A project lists a script that handles its own credentials and prints no value; the script then runs only as the whole command: its path (from the repo root, or absolute in this repo), then plain arguments with no newline, `$`, backtick, `;`, `|`, `&`, `<`, `>`, `(`, `)`, `{` or `}`. A wrapper, env prefix, pipe, look-alike path or symlink to the script is denied. Direct reads of the credential dir stay denied, and a project without the key sees no change.
