* Projects pin the agent team template. `agent-team.sh sync` writes `.claude/agent-team-pin`, and head-checks runs `agent-team.sh check --pinned`, so a merged template change no longer turns open project PRs red. After a template merge, `ship.sh` starts `script/template-sync-pr.sh`, which opens one bump PR per project and lands it with `--verdict-from`. `fleet-watch` reports a pin that lags for more than 24 hours or a red bump PR (#1247).
