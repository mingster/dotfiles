* The guard now denies a blocked script whose name is built at run time: from a variable, glob, brace list, `$'\x..'` string or substitution, or run through `xargs` or `find -exec` with a shell. It also checks each plain line of every command on its own, so a quote in a comment, a heredoc body or an ANSI-C string no longer hides a deny such as a force push. Globs and `xargs` that do not run a shell (`ls bin/*.sh`, `xargs grep`) stay allowed. Closes the follow-ups to #1381 and #1383 in #1385.
